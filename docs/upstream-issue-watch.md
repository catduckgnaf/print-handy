## Upstream issue tracker watches

The weekly upstream issue watch checks Forge-X (`DrA1ex/ff5m`) and OpenCreator (`FlashForge-C5-Modding-Group/OpenCreator`) for recent issues matching the editable keywords in `docs/upstream-issue-watch.toml`. It opens one labeled, deduplicated Print Handy issue per match, including issues previously closed by a maintainer. The watch is notify-only and never writes to upstream trackers. The separate firmware watch continues to track new firmware releases against audited baselines.
